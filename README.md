# Recruitment and Candidate Screening System

A web-based recruitment platform built with ASP.NET Core MVC, C#, Entity Framework Core, SQLite, ASP.NET Core Identity, and Stripe.

🌐 **Live Website:** [Recruitment and Candidate Screening System](http://recruitment-and-candidate-screening-system.runasp.net/)  
`http://recruitment-and-candidate-screening-system.runasp.net/`

---

## Features
- Candidate registration, login, and profile management
- Secure CV, photo, and signature uploads
- Job circular creation, publishing, and management
- Job search, applications, and application tracking
- HR dashboard and application management
- AI-assisted CV-to-job matching
- Payment integration with Stripe Checkout
- Responsive UI for desktop and mobile
- Role-based authentication and authorization

---

## Technology Stack
- **Backend:** C#, ASP.NET Core MVC (.NET 10)
- **Frontend:** Razor Views, HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite, Entity Framework Core
- **Authentication:** ASP.NET Core Identity
- **Payments:** Stripe Checkout
- **Hosting:** MonsterASP.NET

## Run Locally

### Prerequisites
- [.NET 10 SDK](https://dotnet.microsoft.com/)
- [Git](https://git-scm.com/)

### Clone and Run
```bash
git clone https://github.com/Rifat-Bin-Alam/Recruitment-and-Candidate-Screening-System.git
cd Recruitment-and-Candidate-Screening-System
dotnet restore
dotnet run
```

Configure your local database and Stripe test credentials as needed.

## Security
- Role-based access control
- Server-side validation and anti-forgery protection
- Private candidate file storage
- Server-side payment verification
- Sensitive configuration excluded from source control
